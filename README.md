# GitMaps

**Discover high-quality open-source repositories before they become mainstream.**

GitMaps is an AI-powered GitHub intelligence platform. Unlike GitHub Trending — which ranks by absolute star gains and therefore always favors repos that are *already* mainstream — GitMaps analyzes growth across multiple signals (stars, forks, watchers, contributors, commits), normalized by repository age, and renders the open-source landscape as an interactive **semantic map**:

- Every significant repository is a **node**, positioned by AI embeddings and clustered by technology.
- Node **size** reflects momentum; node **color** reflects its technology cluster.
- Pan, zoom, search, and filter to find emerging projects while they're still emerging.

## Features

- **Semantic map** — explore the open-source landscape spatially, inspired by alphaXiv's researcher map
- **Trending** — repositories ranked by momentum (today / 7 days / 30 days)
- **Fast-growing** — young repositories with the highest momentum
- **Repository analytics** — growth history plus a transparent breakdown of *why* a repo ranks where it does
- **Similar repositories** — emerging look-alikes, ranked above the famous twins
- **Semantic search** — ask in natural language, retrieve by meaning
